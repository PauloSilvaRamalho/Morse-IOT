Criadores: João, Laura, Ronald e Paulo.

Morse-IOT são dois sistemas, sendo um local, que permite a utilização de um arduino e protoboard para envio de um código morse até o banco de dados, e o sistema web, que serve para a tradução do código enviado ou a transformação de um texto para o morse.

como inicializar o web: 

OBS: a senha do banco de dados não existe mais por isso o sistema não irá funcionar.

1. abra o terminal e use o comando "cd" para acessar a pasta morseWeb;
2. utilize o comando "php -S localhost:8000" para acessar o sistema localmente;
